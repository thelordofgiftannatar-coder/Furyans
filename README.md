# VALIRYAN FREEHOLD (v0.2)
Native Android browser (WebView + Media3). Build: open in Android Studio, or push to GitHub - the workflow builds a debug APK (Actions > Build APK > artifact).
Adds: media sniffer, "media found" badge, download manager (queue of 3, pause/resume, Range resume, cookies+Referer), HLS save, protected-stream label, ExoPlayer with resume, DIY universes playlist, private tabs (separate profile), ad/tracker host blocking, bookmark import (Netscape HTML).
Not included: PDF reader, DASH download, AES/DRM streams, live streams.
